🚀 COMANDOS DE PUSH A GITHUB
───────────────────────────────────────────────────────────────────────────

📤 MÉTODO 1: subir_github.py (API REST, recomendado)
   python subir_github.py "feat: descripción del cambio"

   ✅ Ventajas:
      · No requiere git push
      · Usa token guardado en ~/.config/cervecera_vgb/token
      · Sube archivos modificados + README actualizado
      · Sin problemas de autenticación

   Ejemplos:
      python subir_github.py "feat: auto-amargor + calibración Stout"
      python subir_github.py "fix: database.py v4 - silenciar warnings"

📤 MÉTODO 2: comitgit.py (git tradicional)
   python comitgit.py "feat: descripción del cambio"
   python comitgit.py "fix: descripción" -a archivo_nuevo.py

   ✅ Ventajas:
      · Commits atómicos (un solo commit para todos los archivos)
      · Historial completo en README.md
      · Detecta archivos modificados automáticamente

⚠️ CONFIGURACIÓN DEL TOKEN (primera vez)
   1. Generar token en: https://github.com/settings/tokens/new
      · Note: cervecera-vgb
      · Expiration: 90 days
      · Scopes: repo (primer checkbox)

   2. Guardar token:
      mkdir -p ~/.config/cervecera_vgb
      echo "ghp_TU_TOKEN_AQUI" > ~/.config/cervecera_vgb/token
      chmod 600 ~/.config/cervecera_vgb/token

📦 COMPILACIÓN — WINDOWS 11
───────────────────────────────────────────────────────────────────────────

1️⃣ INSTALAR PYTHON
   · Descargar desde python.org (3.12 o 3.13)
   · ✅ Marcar "Add python.exe to PATH"

2️⃣ CREAR ENTORNO VIRTUAL
   python -m venv venv
   venv\Scripts\activate

3️⃣ INSTALAR DEPENDENCIAS
   pip install customtkinter fpdf2 pillow pyinstaller

4️⃣ COMPILAR (separador ; en Windows)
   pyinstaller --noconfirm --onedir --windowed ^
      --add-data "recetas_base.json;." ^
      --add-data "recetario_vgb.json;." ^
      --add-data "recetas_base_genericas.json;." ^
      --add-data "logo.ico;." ^
      --add-data "logo.png;." ^
      --icon="logo.ico" ^
      --name "Cervecera_VGB" ^
      app.py

5️⃣ UBICACIÓN DEL EXE
   dist\Cervecera_VGB\Cervecera_VGB.exe

📚 FUENTES TÉCNICAS
───────────────────────────────────────────────────────────────────────────

· OG/Extracto: BeerSmith / Brewfather (PPG × eficiencia)
· FG: atenuación de levadura + ajuste por temperatura de macerado
· IBU: Tinseth (default) / Rager (alternativa)
· Color: Morey (MCU → SRM) · EBC = SRM × 1.97
· ABV: Standard (OG-FG)×131.25 / Alternative
· pH: Alcalinidad residual (Palmer) + acidez del grano
· Agua: DM Riffe (homebrewingphysics) + Kai Troester (braukaiser)
· Estilos: BJCP 2021 + Brewers Association + Norbrygg + SHBF
· Interoperabilidad: BeerXML (beerxml.com)
